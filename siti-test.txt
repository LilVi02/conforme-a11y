# Siti per mettere alla prova Conforme
#
# Uso:  npm start -- --file siti-test.txt --out report-campione --json
#
# Non sono siti a caso: ognuno mette alla prova una cosa diversa.
# Alcuni falliranno (protezione anti-bot, cookie wall, JavaScript pesante):
# i fallimenti sono informativi quanto i successi, perché dicono dove lo
# scanner va reso più robusto.
#
# Conviene lanciarli a gruppi, non tutti insieme: ~15 secondi a pagina.
